1   - PanLED

3   - PanRef

6   - PanRefinv (0 Stop / 1-127 fwSpeed / 128 Stop / 129-255 bwSpeed)  
7   - Dimmer 0  
8   - Dimmer 0 fine  
9   - Dimmer 1  
10   - Dimmer 1 fine  
11   - Dimmer 2

13  - Dimmer 3

17  - Dimmer 5

19  - Dimmer 6  
20  - Dimmer 6 fine  
21  - Dimmer 7

23  - Strope (0 Off / 1-255 Speed)

24  - Master Dimmer  
25  - Effect mode ID  
26	- Effect speed  
27	- Effect intensity  
28	- Effect palette ID  
29	- Effect option  
30	- Red Primary  
31	- Green Primary  
32	- Blue Primary
